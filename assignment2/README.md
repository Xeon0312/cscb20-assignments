## 📖 项目简介

这是多伦多大学 **CSC B20: Introduction to Databases and Web Applications** 课程的作业项目，使用纯 HTML5 和 CSS3 构建了一个响应式课程网站。

## 🎯 项目目标

- 实践 HTML5 语义化标签
- 掌握 CSS3 布局和样式设计
- 实现响应式设计，适配不同设备
- 构建课程信息展示页面

## ✨ 功能特性

- 📱 **响应式设计**：自适应桌面端和移动端
- 🎨 **现代化界面**：清晰的信息架构和视觉设计
- 🖼️ **图片展示**：课程相关图片资源
- 📋 **课程信息**：完整的课程介绍和导航

## 🚀 快速开始

### 本地预览

```bash
# 克隆仓库
git clone https://github.com/Xeon0312/cscb20_a2.git

# 使用浏览器打开
cd cscb20_a2
open home.html
```

### 在线预览

将文件上传到任意静态网站托管服务即可访问。
