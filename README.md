## 📖 项目简介

这是多伦多大学 **CSCB20: Introduction to Databases and Web Applications** 课程的作业合集，涵盖前端开发（HTML/CSS）和后端开发（Flask+SQL）。

## 📁 项目目录

| 目录 | 内容 | 说明 |
|------|------|------|
| `assignment2/` | 课程网站 | HTML/CSS 响应式设计 |
| `flask-app/` | 学生管理系统 | Flask + SQLite 全栈应用 |

## 🗂️ 项目结构

```
cscb20-assignments/
├── assignment2/               # 作业2：课程网站
│   ├── home.html              # 主页
│   ├── home.css               # 基础样式
│   ├── home_desktop.css       # 桌面端样式
│   ├── home_mobil.css         # 移动端样式
│   └── README.md
├── flask-app/                 # Flask 学生管理系统
│   ├── app.py                 # 主应用
│   ├── assignment3.db         # SQLite数据库
│   ├── templates/             # HTML模板
│   ├── static/                # 静态资源
│   └── README.md
└── README.md                  # 本文件
```

## 🛠️ 技术栈

| 技术 | 用途 |
|------|------|
| HTML5 | 页面结构 |
| CSS3 | 样式与响应式设计 |
| Python | 后端开发 |
| Flask | Web框架 |
| SQLite | 数据库 |
| SQLAlchemy | ORM |

## 🚀 快速开始

### 课程网站

```bash
cd assignment2
open home.html
```

### Flask 应用

```bash
cd flask-app
pip install -r requirment.txt
python app.py
# 访问 http://localhost:5000
```
